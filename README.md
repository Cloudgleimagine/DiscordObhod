> Антивирус может сработать на WinDivert.

> Этот инструмент способен использоваться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает компоненты WinDivert потенциально опасными или относящимися к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение; при недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (Cloudflare может оказаться заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите пункт "Разблокировать". При использовании 7-Zip или PeaZip этот этап разрешается пропустить

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Назначение файлов и пунктов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные инструменты:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода для сервисов из `ipset-all.txt`.  
  Этот пункт пригодится при проверке ресурса, который без zapret работает  
  В скобках показывается режим:
    - `none` — ни один IP не проверяется
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord` — иногда это возвращает неожиданно переставший работать клиент
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет никакой реакции

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если этого не случилось, обратитесь к [#522](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Через текстовый редактор, запущенный от имени администратора, откройте файл `hosts` в созданном каталоге
  - Вставьте скопированный текст в конец `hosts` (либо замените ранее добавленный аналогичный блок)
  - Сохраните файл и проверьте подключение ещё раз. Если проблема осталась, убедитесь, что изменения действительно записались.

#### Работоспособность не гарантируется. Если этот способ не помог, используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Cloudgleimagine/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Найденная стратегия может некоторое время справляться с задачей, а затем перестать работать после её обнаружения.
> В репозитории собраны разные варианты обхода. Если ни один не подходит, создайте собственную стратегию на базе одной из имеющихся, изменив её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` -> `Run Diagnostics` и убедитесь, что ошибок нет

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Испытайте другие стратегии, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки, затем в конце выберите Y
- Удалите каталог zapret
- Загрузите последнюю версию со [страницы релизов](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть пункт разблокировки, нажмите его, затем выберите применить и ОК
- Распакуйте архив в новый каталог в корне диска, исключив специальные символы и пробелы
- По очереди проверьте разные скрипты `general` (стратегии). Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и запустите другой вариант
- После выбора рабочей стратегии добавьте её в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. В командной строке Windows (Win+R, `cmd`) найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ним бороться.
- Переберите остальные стратегии, особенно если прежняя раньше помогала.
- Смотрите также [#251](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, с которой открывается сайт YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord.
- Проверьте, заработало ли приложение Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Cloudgleimagine/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если это тоже не помогло, создайте обсуждение в разделе [Discussions](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Опишите её [здесь](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить список ресурсов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить (например, когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется)
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, исключённые из обработки
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
